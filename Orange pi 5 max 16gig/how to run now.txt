Option B — Step-by-Step Upgrade to Kernel RKNPU 0.9.8 (For Qwen3-8B 16K NPU)

Your board already has deb-src configured for linux-rockchip (5.10.0-1012.12) and 373 GB free on your NVMe, so the script builds a drop-in .deb from your exact running kernel source (keeping your current kernel untouched as fallback):

Build the patched RKNPU 0.9.8 kernel .deb (~15–25 min on 8 cores; keep fan on — does NOT install or reboot automatically):

bash
cd /media/sam/MAXSUN5121/orange10g
./scripts/upgrade_rknpu_098.sh --build-098

(Automatically fetches linux-rockchip 5.10.0-1012.12, swaps in Rockchip's official rknpu_driver_0.9.8, applies the two Linux 5.10 compatibility patches for vm_flags_set and rknpu_devfreq.c, and compiles linux-image-*rknpu098*.deb in /media/sam/MAXSUN5121/rknpu-098-build/.)

Back up /boot and install the new kernel .deb:

bash
sudo cp -a /boot /boot.bak-before-rknpu098
sudo dpkg -i /media/sam/MAXSUN5121/rknpu-098-build/linux-image-*rknpu098*.deb
sudo u-boot-update 2>/dev/null || true

Reboot & verify 0.9.8:

bash
sudo reboot
# After reboot:
cat /sys/module/rknpu/version
# Expected output: 0.9.8

Match RKLLM runtime (v1.2.1) and launch Qwen3-8B 16K on the 6-TOPS NPU:

bash
cd /media/sam/MAXSUN5121/orange10g
./scripts/install_rkllm_runtime.sh --version release-v1.2.1
sudo ./scripts/tune_opi5max.sh
./run.sh --https --preset qwen3-8b-rkllm
